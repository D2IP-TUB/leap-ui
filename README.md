## Installation

We strongly recommend using [uv](https://docs.astral.sh/uv/) for environment and package management.

```bash
uv sync
source .venv/bin/activate
```

This will create a virtual environment for the project and install all required dependencies.

## Developer Setup

If you plan to contribute to the codebase, install the development dependencies and enable the pre-commit hooks:

```bash
uv sync --group dev
pre-commit install
```

This installs the linting/formatting tools defined in pyproject.toml and ensures they run automatically before each commit.

## Running the Web Interface (UI)

LEAP provides an interactive web interface for uploading CSV tables, asking questions, and inspecting the step-by-step table reasoning and action candidates generated by the model.

The UI consists of two services:
1. **Backend Model Server (`server.py`)**: Runs the vLLM inference engine, handles Chain-of-Table actions, and executes sampling.
2. **Web Interface (`interface/main_interface.py`)**: Hosts the frontend dashboard for dataset upload, interactive navigation, and table visualization.

### 1. Start the Backend Model Server

Ensure your virtual environment is active and run:

```bash
python server.py
```

Wait until the model finishes loading and you see:
```text
 Server is Ready!
```

> **Note**: GPU allocation and model settings can be configured in `configs/models.yaml` and `configs/default.yaml`.

### 2. Start the Web UI

In a separate terminal (with the `.venv` activated), start the interface server:

```bash
python -m interface.main_interface
```

The interface will be accessible at:
```text
http://localhost:8080
```

### 3. Using the Interface

1. **Upload Dataset**: Drag and drop or browse to select any `.csv` file.
2. **Enter Question**: Input your natural language question regarding the table (e.g., *"Which country won the most medals?"*).
3. **Run Experiment**: Click **Run Experiment** to send the task to the model backend.
4. **Inspect Step-by-Step Reasoning**:
   - **Action List**: Click through individual reasoning steps (e.g., `select_row`, `select_column`, `group_by`, `sort_by`, `end`).
   - **Step Details & Metadata**: View candidate actions generated during sampling, vote counts, and the selected winning action.
   - **Transformed Tables**: Inspect the state of the table at each step with built-in table pagination.
